# Kararsızım

Kararsız kaldığın konularda anket oluşturup topluluğun fikrini alabileceğin bir sosyal anket platformu.

**Canlı Demo:** https://kararsizim-mocha.vercel.app/

### Özellikler
- Kullanıcı kaydı ve giriş sistemi
- Anket oluşturma ve oy kullanma
- Anket sonuçlarını görüntüleme
- Anket paylaşma
- Django Admin paneli ile yönetim

### Teknolojiler
Python, Django, PostgreSQL, Supabase, HTML, CSS, JavaScript, Vercel
